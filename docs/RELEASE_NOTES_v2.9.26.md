# v2.9.26 更新内容

1. 新增一加 15 氧 OS（CPH2747）机型支持：与 PLK110 同硬件同内核，模块内全链路按 PLK110 档位识别运行（DRM-KO 170-199Hz 挡位与一加 15 一致）。该机型由用户社群实测反馈适配，模块行为以装机实测为准。
2. WebUI 新增"禁用日常 LTPO"开关（真我 GT8 Pro 自制 LTPO 专属）：打开后二选一默认"原厂 LTPS"（亮屏闲置降到 60Hz）或"完美禁用 ADFR"（亮屏锁定所选刷新率），息屏仍走 LTPO 降到 1Hz；开关打开即默认选中，不允许空选。
3. 息屏全景息屏（AOD）显示时长可自定义（默认 120 秒，0-3600 秒，0 = 跟随系统）：息屏期间由模块维持显示，到时按系统原生路径熄灭；亮屏立即恢复最高刷新率，无需解锁。
4. 修复子方案切换、策略应用后部分机型框架最低刷新率投票不可达的问题；息屏 1Hz 档位在开发者选项可见。
5. 内置 daemon 版本同步至 2.9.26。
