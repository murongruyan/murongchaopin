## 一句话介绍

`慕容显示增强` 是一个面向 OnePlus / Realme 的 KernelSU、Magisk 显示模块，提供 DTBO 与 DRM-KO 两种后端、刷新率和分辨率管理、风驰节点以及可选的授权增强能力。

**免费版和付费版不是两个模块。严格来说，整个产品只有这一个模块：免费是未授权状态，付费是同一模块完成授权后的增强状态。** 用户只需要安装一个 ZIP，不需要寻找、下载或叠加所谓 Premium 模块。

## 本版亮点

- RMX5200、PLK110、PJD110 的 DRM-KO 后端与机型分派。
- DTBO 后端保留完整的 DTS 工作区、自定义刷新率和原厂备份回滚。
- 风驰调速器独立免费运行，自动识别 ColorOS / Realme UI 与 SoC。
- 明亮玻璃风格 WebUI，底部悬浮导航和整页应用刷新率管理。
- 付费增强在同一 WebUI 内下载、验签和更新，不改变免费底座的安装方式。
- 失败时保留当前可用组件，不热卸载显示模块，不重启 SurfaceFlinger。

## 免费状态可以做什么

未授权也能直接使用：

1. DTBO / DRM-KO 后端选择与基础应用。
2. 自定义超频刷新率、分辨率和全局/应用刷新率配置。
3. RMX5200 已验收的原厂 LTPS 修复路径、风驰节点和运行日志。
4. 原厂 DTBO 备份、恢复、模块卸载和安全检查。

## 授权后解锁什么

取得“显示增强永久授权”后，仍然使用同一个已安装模块，在 WebUI 的“我的”页面登录账号并绑定设备即可按需下载增强组件。授权增强包括：

- Settings 刷新率、分辨率和应用独立刷新率增强。
- 游戏助手与 Scene 的刷新率联动。
- 自制 LTPO、完美禁用 ADFR 和视频动态插帧（抖音）。

授权价格：20 元，一卡一机，永久有效。支付和卡密由慕容调度管理端处理；不需要在 GitHub 下载第二个包。

## 安装步骤

1. 从 GitHub Release 下载唯一安装包 `Murong.Display.Enhancement.zip`。
2. 在 KernelSU 或 Magisk 中刷入模块。
3. **完整重启手机**，不要只重启 WebUI、SurfaceFlinger 或 system_server。
4. 打开模块 WebUI，先确认机型和当前后端，再进行刷新率操作。
5. 首次修改前保留原厂 DTBO 备份；遇到异常时使用 WebUI 的恢复/卸载入口，或按设备维护方式回滚。

## 授权步骤

1. 打开 WebUI 的“我的”页面并登录慕容调度账号。
2. 输入卡密或完成管理端授权确认。
3. 绑定当前设备，等待 WebUI 显示“已授权”。
4. 点击“下载增强组件”，等待签名和兼容性检查完成。
5. 按提示完整重启；重启后页面会显示组件版本和校验状态。

授权下载包含设备、SoC、内核、后端、Manifest 签名和逐文件 SHA-256 检查。网络暂时不可用时，已安装且仍在宽限期内的组件会继续工作；新设备或校验失败不会强行加载未知文件。

## 支持范围与后端说明

- **DTBO**：适合需要修改 DTS 节点、时序或传输参数的场景。
- **DRM-KO**：运行时注入显示模式，不改写 DTBO 高刷 timing；必须匹配目标内核 ABI。
- **风驰节点**：安装阶段按 ColorOS / Realme UI 与 SoC 自动写入 DTBO；SM8850/SM8850P/SM8845 使用 `HMBIRD_EXT`，SM8750/SM8750P/SM8650/SM8650P/MT6991/MT6993 使用 `HMBIRD_OGKI`。当前版本不侧载独立 `hmbird.ko`。

不同屏幕体质、温度、系统版本和内核 ABI 会影响可用最高刷新率。显示超频不是所有设备都能稳定使用同一档位，建议逐档测试，不要直接照搬别人的频率。

## 风险与回滚

显示参数属于低层硬件路径，黑屏、花屏、自动回到安全模式或高刷不稳定都可能是个体差异。出现异常时：

1. 先停止继续切换刷新率，等待系统恢复或执行完整重启。
2. 进入模块 WebUI 使用“恢复原厂 DTBO”或卸载模块。
3. 无法进入系统时，使用 KernelSU 安全模式或 fastboot 恢复原厂 DTBO。
4. 保留 `mode.txt`、DPI 和原厂备份，反馈时附上模块日志、机型、内核版本和当前后端。

模块不会把付费增强组件打进公开 ZIP，也不会在校验失败时覆盖原有可用组件。

## 常见问题

### 为什么看不到 Premium 模块？

因为没有第二个模块。公开发布的是唯一的“慕容显示增强”，付费只是安装后的授权状态。授权后从同一 WebUI 下载增强组件即可。

### DTBO 和 DRM-KO 应该选哪个？

需要修改 DTS 节点、时序或传输参数时选 DTBO；设备支持匹配的 DRM-KO 且希望运行时注入时选 DRM-KO。WebUI 会根据机型给出可用后端。

### 授权后页面仍显示未授权怎么办？

确认账号已登录、设备已绑定、网络可用，然后重新进入“我的”页面。不要重复刷入第二个 ZIP；如果组件下载失败，保留日志并反馈错误码。

### 更新后要不要重新设置 DPI 或刷新率？

v2.9 不主动改动已验收的 DPI、`mode.txt`、当前刷新率选择或 ADFR 状态。更新后只需要完整重启并核对当前状态。
