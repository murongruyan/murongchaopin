# 慕容显示增强 v2.9.23

本版本相对 `v2.9.22` 的有效更新：

- WebUI 页面初始化、底栏切换、应用列表和插帧状态改为异步/按需处理，降低连续切换后的卡顿。
- 应用列表恢复应用名显示，刷新率选择实时生效且不修改 DPI。
- 内置目标设备原生 `curl` 和完整共享库依赖，授权、租约、更新及付费包下载不依赖系统 curl，也不使用 wget 降级。
- 修复表单请求、刷新令牌响应头和 HTTP 错误正文处理。
- 安装限制到 RMX5200、PLK110、PJD110，并忽略切换期间的 `unknown` 前台包名。
- 撤回未验证的自制 LTPO Hook/daemon 接管实验；保留现有 DRM-KO/稳定运行路径。免费 Hook 版本为 81。
