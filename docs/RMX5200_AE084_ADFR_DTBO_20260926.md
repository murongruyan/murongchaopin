# RMX5200 (AE084) ADFR DTBO injection — 2026-09-26

## 结论先行

把同机另一块面板 AC180 的 ADFR 块注入到 AE084 dvt02 的 WQHD timing 节点后，
内核 **确实** 解析并启用了 AE084 的 ADFR：

| 指标 | 注入前 | 注入后 |
|---|---|---|
| `/sys/kernel/oplus_display/adfr_config` | `0x0`（"adfr is not supported"） | `0xe51` |
| `oplus_adfr_parse_dtsi_config` WQHD120 | 无 mapping table | `[120,60,30,20,10,1]` count=6 |
| `oplus_adfr_parse_dtsi_config` WQHD60 | 无 mapping table | `[60,40,30,20,10,1]` count=6 |
| 写 `min_fps` 时是否发命令 | 不发送 | 发送，日志 `[A0033] dsi_cmd: qcom,mdss-dsi-bigdc-adfr-min-fps-N-command` |
| 面板物理 TE（`test_te`） | 60 | 60（**不跟随**） |

即：**框架→驱动的 ADFR 通路打通了**，但 AE084 的 DDIC 不认 AD296/AC180 那套寄存器。

## 为什么 AE084 之前完全没有 ADFR

本机 DTBO 里同一块板子（TE gpio `0x56`、reset gpio `0xab`、panel-gpio1 `0x93`、
panel-gpio2 `0x36`、物理尺寸 `0x9d x 0x47` 全部相同）有两家面板：

- `AC180_P_3_A0020`：完整 ADFR（`oplus,adfr-config = <0xe51>`、三家命令族、
  mapping table），命令用 `FF 5A A5 2D` 页。
- `AE084_P_3_A0033`（dvt02/dvt03）：**零 ADFR 属性**，初始化命令用
  `F0 55 AA 52` 页族（另见 `FF AA 55 A5 80/81/82`），完全没有
  `qcom,mdss-dsi-*-adfr-min-fps-*` 属性。

AD296（1+15）与 AC180 的 min-fps 命令族逐字节一致，属于同一 DDIC 家族。

## min-fps 寄存器值的通用规律（已解出）

寄存器值 = `节点基频 / 目标fps − 1`（以该基频的帧周期为保持单位）：

- 120 基频节点：`00 01 03 05 0b 77` → 120/60/30/20/10/1
- 60 基频节点：`01 02 03 05 0b 77` → 60/40/30/20/10/1
- 90 基频节点（AD296）：`85` 寄存器，`00 01 02 05 08 59` → 90/45/30/15/10/1

所以**数值是通用的**，面板私有的只有「写在哪个页、哪个寄存器」。

## 注入内容

`tools/inject_rmx5200_adfr.py` 对 DTBO 的 0–3 号 entry 中
`qcom,mdss_dsi_panel_AE084_P_3_A0033_dsc_cmd_dvt02` 节点做两件事：

1. 面板级插入：`qsync-min-refresh-rate`、`qsync-enable`、
   `oplus,adfr-test-te-gpio = <0xffffffff 0x55 0x0>`、`oplus,adfr-config = <0xe51>`。
2. `timing@wqhd_sdc_120` 与 `timing@wqhd_sdc_60` 各插入 37 行：
   三家命令族（bigdc reg `0x84`、hpwm/adfr reg `0x83`）的 min-fps 0..5
   command / command-state，加 `oplus,adfr-min-fps-mapping-table`。

`0x83`/`0x84` 页面为 `FF 5A A5 2D`；命令字节与 AC180 模板逐字节一致。

## 已知缺口

`test_te` 在 `min_fps` 被写成 60/30/10/1 后始终为 60，即面板物理刷新率没有变化。
驱动把命令发出去了，但 AE084 的 DDIC 忽略 `FF 5A A5 2D` / `0x83`/`0x84`。
下一步需要 AE084 自己的低刷寄存器；候选是它自己的 `F0 55 AA 52 08 00` 页 `0x68`
寄存器族（`00`=60 / `01`=90 / `10`=120 / `30`=144，来自原生
`qcom,mdss-dsi-fps-switch-*`），或 `a9` timing 表。
