# 慕容显示增强 v2.9.1

这是 v2.9 的安装脚本修复版本，模块功能和免费/授权架构保持不变。

## 修复内容

- 修复 v2.9 刷入模块时音量键无响应：安装器现在使用一个连续的 `getevent` 事件流读取完整的按下与抬起，不会在重新打开输入设备时丢失抬起事件。
- 原厂 DTBO 基线确认与 DTBO/DRM-KO 后端选择仍是两次独立操作；脚本会等待每次按键完整抬起并执行短防抖，不设超时，也不会默认选择 DTBO。
- 第一次音量+只确认当前为官方原厂 DTBO，不会单独修改分区；第二次音量+才选择 DTBO 修改和刷写，音量-选择 DRM-KO。

## 安装说明

在 KernelSU、Magisk 或 APatch 中刷入 Release 附带的 `Murong.Display.Enhancement.zip`，按屏幕提示完成两次音量键操作，然后完整重启设备。
