# 慕容显示增强 v2.9.25

## 新增机型：一加 Ace 6（PLQ110）

- 新增 PLQ110 支持：SM8750 平台 6.6.118 android15 GKI 内核，AA605 面板 1272x2772。
- DRM-KO 后端提供与一加 15 相同的 170/175/180/185/190/195/199Hz 扩展挡位（尚未真机验证，PLQ110 用户请谨慎测试并反馈）。
- HMBIRD 按 Ace 6 原厂 DTBO 的 OGKI 节点处理；安装白名单已放行 PLQ110。

## 修复：付费组件自愈安装

- 修复付费资源包安装记录残留但运行文件缺失时，WebUI"安装最新付费包"误报"已是最新"导致无法自愈的问题。
- 现在按付费包 Manifest 逐文件校验 payload 完整性；缺失或部分损坏时自动重新下载、校验并安装，重启后生效。
- 授权面板如实显示付费组件安装状态；自定义插帧、自定义刷新率的保存与回读路径不变。

## 其他

- 内置 daemon 版本同步至 2.9.25。
- 付费组件需 1.1.11 及以上（含 PLQ110 ADFR 锁 KO 与 6.6 内核支持）。
