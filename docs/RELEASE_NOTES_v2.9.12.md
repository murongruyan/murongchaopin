# 慕容显示增强 v2.9.12

## 付费用户安装/升级流程修复

- 刷入模块时如果检测到付费载荷（升级保留的旧付费包或刚下载的新付费包），立即同时安装付费 Hook，不再只装免费 Hook、等开机后才装付费。
- 开机阶段付费 Hook 更新不再卸载免费包；只有证书不匹配时才单独重装付费包，免费 Hook 始终保持安装。
- 模块内置 sqlite3，在安装/更新 Hook 后自动恢复 LSPosed 的启用状态与作用域（免费：system/KernelSU；付费：system/设置/游戏助手/Scene/视频），刷入后只需重启一次。
- WebUI 授权下载并安装付费组件时同样在重启前恢复付费 Hook 作用域，避免二次重启。
