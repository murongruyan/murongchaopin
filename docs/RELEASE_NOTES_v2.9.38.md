# 慕容显示增强 v2.9.38
## v2.9.38

1. **修复 v2.9.37 引入的周期性黑闪与 dpi/分辨率跳动（回退）**：v2.9.37 把厂商
   OTI 暂停补丁的心跳间隔从 500ms 放宽到了 1500ms，导致补丁跟不上厂商 OTI 的
   投票节奏 —— 屏幕静止几秒后面板会在 `1440x3136` 与 `1080x2352` 之间来回切，
   表现为周期性黑闪、`wm size`/dpi 乱跳（即 v2.9.33 修好的那个问题被重新引入）。
   本版把间隔改回 **500ms** 并加注释说明该节奏是修复的一部分、不是可优化的开销。
2. 内置 daemon 版本同步至 2.9.38（免费核心与付费 daemon 同源重建）。
3. v2.9.37 的其它内容（ColorOS 17 全量适配、删除自制 LTPO）不变。
