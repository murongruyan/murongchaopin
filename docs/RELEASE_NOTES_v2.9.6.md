# 慕容显示增强 v2.9.6

本版本补齐免费底座更新时的付费授权续装，以及 WebUI 的付费组件更新日志。

## 更新内容

- 更新免费模块时保留账号、签名租约、组件状态和当前已安装的付费资源。
- 已有有效授权和账号 Token 时，刷入脚本自动查询设备兼容的最新付费组件，并按 `version_code` 选择最高版本。
- 已经是最新版本时不重复下载；网络、服务器或组件校验失败时继续完成免费模块安装，并保留当前付费组件。
- 下载后仍执行整包 SHA-256、Ed25519 Manifest 签名、版本、设备、SoC、内核、后端、目标路径和逐文件哈希校验，再进行原子替换。
- WebUI 更新弹窗新增付费组件发布日志，支持多行和滚动显示；更新判断和弹窗去重优先使用数值版本码。

## 验证结果

- Shell、JavaScript 语法和 Git 差异检查通过。
- RMX5200 隔离模块目录完成 `updated` 与二次 `current` 自动续装闭环。
- 授权门禁真机回归全部通过，包括有效/宽限租约、旧调用兼容、版本码落盘、篡改包、软链接和未声明文件拒绝。
- 真实模块查询当前已发布组件时返回 `status=current`，未重复下载，也没有重启设备或重新加载显示组件。

## 安装说明

在 KernelSU、Magisk 或 APatch 中刷入 Release 附带的
`Murong.Display.Enhancement-v2.9.6.zip`，然后完整重启设备。已有付费授权会在刷入阶段自动续装最新兼容组件。
