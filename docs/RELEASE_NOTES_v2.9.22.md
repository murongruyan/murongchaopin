# 慕容显示增强 v2.9.22

本版对应当前工作区的显示超频、刷新率配置和付费构建修复。

- RMX5200 DRM-KO 使用固定最大链路时钟，并按源 timing 推导 VFP/VTotal，减少亮度和色彩漂移。
- `mode.txt` 作为全局/应用刷新率唯一真值；设置页、自定义应用刷新率、搜索和游戏助手共享同一份配置回显，刷新率路径不修改 DPI 或分辨率密度。
- 系统应用列表切换改为后台加载、主线程提交并强制刷新列表，搜索结果与主列表共用同一份结果。
- WebUI、KO 构建和付费打包统一传递固定链路参数；付费构建保留 Release 工作流并增加 Artifact-only 入口。
