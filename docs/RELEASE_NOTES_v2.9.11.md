# 慕容显示增强 v2.9.11

## Hook 修复与签名统一

- 显示设置 Hook（免费端）改为与付费端一致的慕容调度证书签名；升级安装时先卸载免费/付费两个旧包再安装新包，避免旧证书与旧代码残留导致 Hook 失效。
- 修复游戏助手刷新率面板：新增 `Activity.onResume` 与设置 Activity 生命周期补丁，性能设置页直接注入当前分辨率下的档位（60/90/120/123/144/150/155/165Hz）。
- Scene 与设置页刷新率、视频插帧（MEMC）Hook 已在真机验证恢复。

## 机型支持

- 恢复 PLK110（一加 15）DRM-KO 支持：不再被安装脚本拒绝，默认档位 170/175/180/185/190/195/199Hz；KO 保留面板、DT、模式数组、私有 timing 与 offset 的 fail-closed 校验。

## 构建发布

- GitHub Actions 现在在 CI 中编译并签名免费 Hook APK，再打包公开模块；付费组件继续走独立私密仓库，不进公开 Release。
- 付费端独立发布 1.0.5（token 授权、整包 SHA-256 与逐文件校验，完整重启后生效）。
