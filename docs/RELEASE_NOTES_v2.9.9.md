# 慕容显示增强 v2.9.9

本版本是 v2.9.8 之后的公开底座更新，付费增强组件仍由授权后按设备兼容性从服务器下载。

## 更新内容

- 更新检查改为通过慕容调度服务器版本接口获取版本、下载地址和更新日志，避免直接访问 GitHub Raw 产生 429 或缓存异常。
- 优化 WebUI 页面切换和授权刷新，应用列表仅在对应页面活跃时加载，减少切换时的阻塞和卡顿。
- API 102 的游戏助手与 Scene 刷新率选择改为四列平铺，并从 root bridge 补齐当前分辨率下的全部刷新率节点。
- 新增 Web 授权流程、服务端更新契约和 UI 性能回归检查；公开 Hook 仍不包含付费 Hook 类。

## 安装

在 KernelSU、Magisk 或 APatch 中刷入 `Murong.Display.Enhancement-v2.9.9.zip`，然后完整重启设备。
