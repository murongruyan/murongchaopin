# 慕容显示增强 v2.9

慕容显示增强始终只有一个模块安装包。未授权时，DTBO / DRM-KO 超频、自定义刷新率、基础刷新率与分辨率控制、原厂显示策略、风驰节点和回滚能力均可直接使用；取得永久授权后，仍在同一模块 WebUI 内下载增强组件，不需要安装第二个模块。

## 本次更新

- 全新明亮玻璃 WebUI 与悬浮底栏，重做超频、刷新率、插帧和“我的”页面交互。
- 内置慕容调度账号、20 元永久授权、卡密绑定、组件下载、离线宽限和更新状态。
- Settings 刷新率/分辨率/应用独立刷新率、游戏助手、Scene、自制 LTPO、完美禁用 ADFR 和抖音视频插帧在授权后按需启用。
- 新增 RMX5200、PLK110、PJD110 的 DRM-KO 后端；OnePlus 12 同步保留原有电池解容参数。
- 风驰调速器改为独立免费 KO，按系统与 SoC 自动选择 HMBIRD_EXT / HMBIRD_OGKI。
- 增强组件加入 Ed25519 签名、逐文件哈希、设备兼容性校验与原子更新，失败时保留当前可用版本。

## 安装说明

在 KernelSU 或 Magisk 中刷入 Release 附带的 `Murong.Display.Enhancement.zip`，完整重启后从模块 WebUI 使用。已有用户可直接覆盖更新；本次发布不会主动修改现有 DPI、`mode.txt`、刷新率选择或 ADFR 状态。

显示超频存在个体差异。出现黑屏或花屏时请强制重启，并在安全模式或 fastboot 中使用原厂 DTBO / 模块回滚能力恢复。
