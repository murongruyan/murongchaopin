# 慕容显示增强 v2.9.18

本版是免费模块与授权增强组件的合并发布，付费组件仍由模块在设备上完成授权下载，不会进入公开模块 ZIP。

## 更新内容

- 模块升级按当前 slot 实际 DTBO 分区哈希路由。软件层修 bug 更新不会重复刷写已应用 DTBO，也不会覆盖用户刷新率、游戏助手、视频插帧、DRM-KO 档位或原厂备份；旧版 `*-final.img` 在哈希匹配时自动迁移，未知签名只警告并继续安装软件组件。
- 游戏助手同时 Hook 设置页和游戏侧边栏，刷新率表、插帧、超分辨率和超 HDR 入口互不串位，重复点击/刷新不会把一级界面按钮改成刷新率表。
- 付费 Hook 的侧边栏生命周期和能力探测经过稳定性与性能修复，Hook/daemon 版本同步更新到 v69；LTPO 在游戏或场景切换分辨率后会恢复正确显示几何。

详细变更见仓库中的 `changelog.md`。
