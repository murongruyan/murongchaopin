# 慕容显示增强 v2.9.3

这是 KernelSU 安装界面第二步提示的修复版本，其他模块功能保持不变。

## 修复内容

- 修复第二次 DTBO/DRM-KO 后端选择只写入导出日志、不在 KernelSU 安装界面实时显示的问题。
- 后端选择函数改为正常调用并直接设置结果变量，提示通过标准输出实时显示，不再藏在命令替换的错误流中。
- 继续使用简单单事件音量键读取；第一次确认后等待 1 秒，再进入第二次选择，不设超时且不默认选择 DTBO。

## 安装说明

在 KernelSU、Magisk 或 APatch 中刷入 Release 附带的 `Murong.Display.Enhancement-v2.9.3.zip`，按界面提示完成两次音量键操作，然后完整重启设备。
