# 慕容显示增强 v2.9.51

本版修复部分用户在 KernelSU / SukiSU 中无法安装模块的问题，重点解决 OnePlus Ace 6（PLQ110）被错误识别为未知机型的安装中断。

## 安装修复

- 反馈日志中，原厂 DTBO 校验、备份、解包和 AVB 信息提取均已完成，安装在 `process_dts` 的机型识别阶段退出：
  `Unknown Model (PLQ110)`，随后显示“修改 DTS 失败”。
- 根因是已发布包携带了旧版 `bin/process_dts`，与已经支持 PLQ110 的源码不同步。本版重新编译并更新该工具。
- 支持机型仍为 RMX5200、PLK110 / CPH2747、PLQ110、PJD110；未知机型拒绝和原厂 DTBO 校验继续保留。
  日志中的 DTC 格式警告不是这次安装中断的原因。

## 构建和打包保护

- 为 `process_dts` 增加源码 SHA256 记录，打包前拒绝缺失、空文件、无效指纹及过期构建。
- Windows 构建脚本固定从自身目录定位；编译器返回失败时立即退出，不能以旧二进制存在作为构建成功的依据。
- CI 使用本次构建的新工具和指纹进行检查并交付，避免复用仓库中陈旧的本地产物。
- 公版打包与独立审计覆盖固件后缀不同的付费 MEMC 库及各机型付费 ADFR 模块，不把授权组件打入公开安装包。
- 免费守护进程版本与模块同步，普通 CI 和正式发布均检查版本一致。
- 授权原生组件撤销或跳过时，清理对应开机暂存，避免跨启动残留被自动挂载。

## 离线验证

- 通过真实属性读取入口检查全部已支持型号，并验证未知型号拒绝后不会修改输入 DTS。
- 使用 PLQ110 面板 fixture 执行安装器同一路径，检查生成档位及原有档位保留。
- 验证源码指纹、Windows CRLF / Linux LF 兼容，以及缺失、空文件、过期构建的打包拒绝行为。
- 隔离验证授权原生组件暂存清理：撤销、跳过或启动入口缺失时清理，正常授权路径及其他文件保留。
