# PLK110 的 DTBO 档位组合由真机实测决定，不是由"最高时钟"决定：
#   175,185,195,199        -> 7 个组内 timing，去 123、含 199（本版默认）
#                             10 Hz 等距，步进 +6.1%/+5.7%/+5.4%/+2.1%，最大 6.1%
#   123,175,180,185        -> 7 个组内 timing，实测可开机（C185 / T1）
#   123,170,175,180,185    -> 8 个组内 timing，实测【开不了机，落 fastboot】（D_safe / S1）
#   123,199                -> 5 个组内 timing，实测可开机且 199Hz 上线（F199 / T2）
# 规律（PLK110 本机 10 次观测）：组内 timing <= 7 可开机，>= 8 必挂；机制未明。
# 已由 P7/P8 受控实验确认：7 通 / 8 挂，与"哪些档位"无关（只差一个 185 档）。
# 去 123 不换来额外名额（123 自己占一个），但阶梯更平顺：
#   去 123（175,180,185,199）排序后最大单步 7.6%
#   留 123（123,175,180,199）排序后最大单步 42.3%（123->175 那一跳）
